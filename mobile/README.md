# Dalailul Khairat Mobile

Expo Router app for reading Dalailul Khairat in Arabic and English. Content is bundled in `data/dalail-content.json`; reading progress, daily completion, and bookmarks are stored locally with AsyncStorage.

## Start

```bash
npm install
npx expo start
```

Open the project in Expo Go, an Android emulator, an iOS simulator, or run the web target with `npm run web`.

## Checks

```bash
npm run lint
npm run typecheck
```

Everything required to build and run the mobile app is contained in this directory.
